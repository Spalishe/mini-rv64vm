# mini-rv64vm
More lighter version of my RV64-VM emulator, created as school project.

# Dependencies
 * gcc
 * cmake
 * make

# Build
```
git clone https://github.com/Spalishe/mini-rv64vm.git
cd mini-rv64vm
make
```

# Running
```
./build/mini-rv64vm path_to_dtb path_to_firmware path_to_initrd(optional)
```
